## 限制

这是源码与发布产物审查，不是渗透测试或无漏洞保证。HTTP仅用于受信任本地开发，生产应使用HTTPS。会话不是加密保险箱，显式 show-token/API 调用及授权分析数据仍须由操作者保护。未隔离同一OS用户持续修改目录的竞争攻击。五类宿主自主执行业务、真实生产账号写操作不属于本次验证范围。

对解包产物与新仓库历史重复扫描后才能发布；具体产物SHA-256及源码提交见GitHub Release的 release.json。漏洞报告遵循 [SECURITY](../SECURITY.md)。
